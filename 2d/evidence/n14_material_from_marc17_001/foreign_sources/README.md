## Default inspection: no factory, simulator or reset

`audit_source.py` and `public_support.py` are NEW public adapters outside the
original identity. They do not rewrite/resign original evidence. Obtain the
SHA256 of `files.json` from the externally published source/release receipt,
then run in a fresh interpreter:

    PYTHONDONTWRITEBYTECODE=1 python3 audit_source.py \
      --expected-files-sha256 EXACT_EXTERNALLY_PUBLISHED_FILES_SHA256

The default checks the exact bounded archive file inventory, every copied
source/input byte, original identity mapping, controller/configuration/model
bindings and absence of unlisted files or symlinks. It imports no rage_mill
module, factory, reset generator or MuJoCo. Python3.11+ standard library is
sufficient. Keep this inventory directory clean; write audit outputs elsewhere.

Add `--tables` with an existing NumPy environment to inspect the exact18-field
NPZ without loading any controller. This rejects duplicate/encrypted/unexpected

nonliteral650prefixes, non-F32 actions, wrong Q or terminal value. It does not
execute dynamics or infer task success. `--out NEW.json` refuses overwrite.

## Explicit exploratory controller loading API

In a separate fresh Python process, callers may explicitly use:

    from public_support import load_controller
    policy, disclosure = load_controller(
        expected_files_sha256='EXACT_EXTERNALLY_PUBLISHED_FILES_SHA256')

This function is NOT invoked by the CLI or preparatory smoke checks. It verifies
all bytes/arrays first, refuses existing rage_mill imports, and creates a NEW
in-memory loading view mapping original pins to their hash-identical public
copies. It then invokes the unchanged source-defined zero-offset controller
factory. The original identity JSON and original absolute execution paths
remain immutable provenance. No historical identity hash or qualification is
awarded to the local view. Construction alone issues no policy command, model
construction, native step or reset; later calls to the returned policy at
launch create native forecast models and incur the declared bounded work.

The original runtime is Linux/aarch64, Python3.12.3, NumPy2.5.2, MuJoCo3.3.5 and
one OMP/OPENBLAS thread. It is bound by original-path native file hashes that
this archive does not redistribute. Runtime metadata must match by default.
Explicit `allow_runtime_mismatch=True` permits exploratory loading only, still
requiring MuJoCo3.3.5 and both OMP_NUM_THREADS=1/OPENBLAS_NUM_THREADS=1. Matching
metadata never establishes matching native binaries, portable execution or a
requalified result. The disclosure always reports runtime_binary_hashes_verified
false, loading_view_is_new true and qualification false.

There is no public label-activation adapter. Frozen original reserved-runner
